# Earth observation data cubes integrated with drone imagery, health and climate data for health response systems - Paper files

This repository contains the csv, source code, data and results of the paper **Earth observation data cubes integrated with drone imagery, health and climate data for health response systems**.

## Directory structure

This repository is organized as follows:

- `source`: contains the paper code used in 
- `data/raw`: contains the experiment's input data
- `data/output`: contains the experiment outputs
